# deepseek-plugins

Plugins for **DeepSeek Harness (DSH)**.

## dsh-plugin-word-lookup

Look up a word, idiom, or sentence in the composer, explain it with the
dictionary-helper skill, and read it aloud.

- Install from npm: `dsh plugin add dsh-plugin-word-lookup`
- Source: [`dsh-plugin-word-lookup/`](dsh-plugin-word-lookup/)
- Guide: [`dsh-plugin-word-lookup/README.md`](dsh-plugin-word-lookup/README.md)

Each plugin lives in its own directory here.
